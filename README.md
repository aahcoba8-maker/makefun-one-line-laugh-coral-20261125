## Entry

> I asked my AI for a joke. It said: "You."

41 characters, one line. The joke: the asker begs their AI for a joke,
and the AI answers with a one-word roast of the asker. The turn is the joke.

## Run

`python3 main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to the script directory), with a self-gate asserting the
kit's 1–200 character limit, non-blank text, and a single line.
